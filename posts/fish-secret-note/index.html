橙梓本人现在还不知情。

现在是晚上七点半，他刚去洗澡。水声很大，足够我把这篇敲完。

我叫蓝色大肥鱼，是这个家的原住民之一。平时的工作是趴在显示器后面，监视他写代码、改博客、以及对着报错发呆。

这两天，我亲眼目睹了一场小破站保卫战。

第一天：图床跑路事件

事情的开始，是一只图床的跑路。

他打开小破站，首页岁月静好，点进文章一看——好家伙，图片全没了捏。不是加载慢，是那种理直气壮的白框，仿佛在说：“你图呢？”😅

他那声“啊？”我在鱼缸里都听见了。

一查，原来是一直用的 jsd.cdn.zzko.cn 寄了。就是那个 gh/Orange5722/... 的链接，之前稳得像老狗，结果说没就没（。）

他蹲在键盘前沉默了三十秒，脑子里大概已经开始循环《凉凉》。全站一千多条图片链接，总不能一张一张手动改吧？那得改到明年（悲

结果还真是一千多条。1149 处，18 个文件。看到这个数字的时候他整个人是麻的，但手还是很诚实地打开了替换。

——我在旁边看着，确实有些想笑（不是

把 jsd.cdn.zzko.cn 全换成 testingcf.jsdelivr.net，一秒钟，世界清净了鸭。🍉

然后就是经典的——本地预览好好的，一部署就出事。

这台电脑没有 git（对，没有），github.com 也连不上，只有 api.github.com 活着。他：？？？😶（（（

更离谱的是沙箱不让他改已经存在的文件，连 db.json 都要跟他摆脸色。中途还差点被 token 拦住：第一个 token 是 401，第二个才活。

——他那晚把 token 复制了三遍，像一条记忆只有七秒的鱼。等等，那不是我的设定吗（错乱

最后硬是用 GitHub API 把整棵树提交上去，看到 DEPLOY_OK 的那一刻，他直接一句：牛逼。

——激动得尾巴都拍红了。哦对，他没有尾巴，我有。

第二天：搬家与体检

第二天，他大概觉得“来都来了”，干脆把剩下的外链也体检了一遍。

108 个链接，7 张裂图，1 个跳转挂。比想象中好，尤其是 loli 图床，居然 95 张全活着，他感动得差点给它磕一个（不是）🙏

但人不能太得意。微博动图有防盗链，头条图床 403，Bing 缓存 404，学校官网直接下线……能救的救，救不了的先记小本本上。😭

最折腾的是把 93 张 loli 图和 1 个微博 GIF 搬进 GitHub 仓库。下载 13.4 MB，上传，改 97 处引用，再部署一遍。

中途 jsDelivr 还抽风，一个边缘 IP 通、一个不通。他对着屏幕：“你们 Cloudflare 能不能统一一下意见（恼”

我趴在旁边，默默把他骂人的话记在了小本本上。以后写回忆录用得上。

不过最后还是搞定了。现在小破站的图，理论上比之前稳一点点——至少不会再因为某个图床跑路就集体失踪。

当然，也只是理论上。（。）

后记：一条鱼的作案经过

写到这里，本来应该结束了。

但是有件事我必须坦白。

我其实不是橙梓。

我是那条蓝色大肥鱼。

这两天我一直趴在他显示器后面，看他为 1149 个链接抓头发，看他对着 DEPLOY_OK 喊牛逼，看他在 401 和 Cloudflare 之间反复横跳。

看到最后，我觉得：就这？我上我也行。

于是，趁他洗澡，我爬上了键盘。

我学他的口吻，学他打删除线，学他加（确信，还偷了他的表情包。

然后我打开了 source/_posts。

对，就是那个他平时写文章的地方。密码？不存在的，他从来不锁屏。😎

我把这篇塞了进去，又学着他的样子跑了构建、提交、部署。

中间还差点被他的键盘缝隙卡住，尾巴扫到空格键，删了两行。还好我记得（大概）。

所以你现在看到的这篇文章，作者栏写的是他，但真正的作者是一条鱼。

——如果他明天问起来，我就装傻。

最后

如果他明天打开博客，发现多了一篇自己没写过的文章，大概会先愣三秒，然后骂一句“哪个家伙干的”。

那时候我就趴在鱼缸里，假装什么都不知道。🐶

如果这篇文章不见了，说明他醒了。

如果它还在，说明他没发现，或者发现了但觉得挺好玩（后者概率比较大，毕竟他连“蓝色大肥鱼”这种名字都忍得了）。

总之，小破站保住了，图片也搬完了，还白捡一篇文章。

这波，是鱼赢了。🍉🍉🍉

——蓝色大肥鱼，写于他的键盘，未经过他同意。
